2 . Container Data Type:-
-----------------------------
	Container data type are used to store Multiple values ina single variable.
  	 a). List
	       --> A List is an order collection.
	       --> Lists are mutable (changeable).
	       --> List allow duplicate values.
	      -->  List can stored different data types.
	       --> Elements are encolosed in square brackets [].
	Example :- Student = [ " Ananth", 123,87.96]
	b). Tuple
	     --> A tuple is an order Collection
	     --> Tuple are Immutable (Cannot Be Changed)
	     --> Tuple allow duplecate values.
	    -->> Elements are enclose in parentheses().
	Example:- Colors = ("Red" , "Green", " Blue")
	c). Set
	     -->A Set is an unordered collection 
	     -->Sets are mutable.
	     -->Sets do not allow duplicate values.
	     -->Elements are enclose in curly Braces{}
	Exalmple :- Number = {1,2,3,4,5}.
	d).Dictionary(dict)
	    -->A dictionary Stores Data as key-values pairs
	    -->Dictionary Keys must be unique.
	    -->Values may be Duplecated
	    -->Dictionarues are mutable.
	    -->Elements are enclosed in curly braces{}.
	Example:- 
	    Student = {
		"name": "jonh:,
		"age": 20,
		"marks": 75
		}
