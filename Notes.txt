List in HTML
--------------
-> Collection of data or information or items
-> Types of List
    1. Ordered List
    2. Unordered List
    3. Description/ Definition List
    4. Nested List

1. Ordered List
    -> In HTML to display ordered list here need to use <ol></ol>
    -> This ordered list contains list items <li></li>

    Ordered List Attributes
    -----------------------
    1. Type: 1, a, A, i, I
    2. Start: 
    3. Reversed

2. Unordered List   
    -> In HTML to display ordered list here need to use <ul></ul>
    -> This ordered list contains list items <li></li>

    Unordered List Attributes
    -----------------------
    1. Type: none, desc(default value), square, circle

3. Description List/ Definition List
    1. <dl></dl>  Definition List
    2. <dt></dt>  Definition Term
    3. <dd></dd>  Definition Data 

4. Nested List



  Table's in HTML:-
  ------------------
        -> The Collection of row's and columns or Collection of cell's 
           is called as a Table.
        -> to design table in web page here we need to use table tag 
           <table></table>

           Table tags:-
           -----------
             1. <tr></tr>               ->table row             
             2. <td>,</td>              ->table             
             3. <th></th>
             4. <thead></thead>
             5. <tbody></tbody>
             6. <tfoot></tfoot>
             7. <colgroup></colgroup>
             8. <col>
    Table Attributes:
    ----------------
            1. border: 
              -> the space between padding and marginn 
            2. cell spaceing:
                -> The space between cells in Table.
            3. cellpadding:
                -> The space b/w cell contet and cell border
    tABLE call Attributes(td/th):
    ----------------------------
            1. colspan : used to marge columns in table.
            2. rowspan : used to marge rows in Table.
